# 🎮 PC Gaming Quiz

A simple multiple-choice quiz written in Python featuring questions about popular PC games.

## 📌 Features

* Multiple-choice gaming questions
* Score tracking
* Accuracy calculation
* Immediate feedback for each answer
* Option to quit the quiz using `Q`
* Covers games such as:

  * Elden Ring
  * Valorant
  * Cyberpunk 2077
  * Minecraft
  * Red Dead Redemption 2
  * Counter-Strike 2
  * The Witcher 3
  * Wuthering Waves
  * Baldur's Gate 3
  * Clair Obscur: Expedition 33

## 🛠️ Technologies Used

* Python 3

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/pc-gaming-quiz.git
```

Navigate into the project:

```bash
cd pc-gaming-quiz
```

Run the quiz:

```bash
python pc_gaming_quiz.py
```

## 🎯 Gameplay

Choose the correct option by entering:

```text
A
B
C
D
```

You can quit at any time by entering:

```text
Q
```
